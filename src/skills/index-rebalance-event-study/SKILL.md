# 指数调样事件研究 (Index Rebalance Event Study)

围绕宽基指数（沪深300、中证500、中证1000、科创50、创业板指等）的定期调样与特别调整，梳理事件时间线、受影响个股与潜在被动资金流。

## Workflow Checklist

- [ ] 1. 确认标的指数与事件窗口（公告日 / 生效日）
- [ ] 2. 拉取当前成分股名单（get_index_constituents）
- [ ] 3. 检索调样公告与新闻（domestic_search）
- [ ] 4. 定位调入/调出个股并估算被动资金影响
- [ ] 5. 关联跟踪产品规模（get_index_etf_map）
- [ ] 6. 输出事件研究报告

## Steps

1. **确认标的与窗口**
   - 用 `get_index_constituents` 解析用户所指指数，得到当前成分股（代码/名称/最新价）。
   - 明确调样类型：A 股主要指数的定期调样通常每年 6 月、12 月实施（以公告为准），也有临时调整（并购、风险警示、退市等）。
   - 若用户只给"最近调样"，以最近一次定期调样为窗口。

2. **检索公告与新闻**
   - 用 `domestic_search`（command: `news` 或 `announcements`）检索关键词，如：`<指数名> 调样`、`<指数名> 样本调整`、`<指数名> 成分股 调整 生效`、`纳入 剔除 指数`。
   - 记录：公告日、生效日、调入名单、调出名单、调整原因（如有）。

3. **定位受影响个股**
   - 对比新旧成分：调入 = 新增，调出 = 移除（若无历史名单，直接采用公告名单）。
   - 对重点个股用 `get_market_data` 取行情/估值，判断事件前后的价格与成交变化。

4. **估算被动资金影响**
   - 关键度量：`被动资金 ≈ 跟踪该指数的 ETF/指数基金规模合计 × 个股在指数中的权重`。
   - 权重来源提示：本工具当前**不提供成分股权重**（`weightsIncluded: false`）；可用指数总规模与个股市值 / 指数总市值做粗略代理，或在报告中明确标注为估算。
   - 用 `get_index_etf_map` 取跟踪该指数的主要 ETF 及规模，估算被动买入/卖出金额。

5. **输出结构**
   - 一句话结论（本次调样看点、最受损/受益个股）
   - 事件时间线（公告日 → 生效日）
   - 调入 / 调出清单表（代码 | 名称 | 最新价 | 涨跌幅 | 估算被动资金）
   - 关联 ETF 与规模表（代码 | 名称 | 公司 | 最新净值）
   - 风险提示

## Caveats

- 成分股权重不在本工具覆盖范围内，被动资金流为**估算值**，受权重、跟踪误差、基金申赎影响。
- 调样公告与生效日请以指数公司（中证 / 国证 / 上交所等）官方公告为准；`domestic_search` 结果为新闻/公告聚合，可能存在滞后或遗漏。
- 事件研究仅描述历史规律，**不构成对未来收益的预测**。
- 本内容仅供研究参考，**非投资建议**。
