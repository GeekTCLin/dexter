# 市场广度复盘 (Index Breadth Review)

## Workflow Checklist

复制以下清单到回答中，逐项推进：

- [ ] 1. 拉取市场广度数据（涨跌家数 / 涨跌停 / 成交额）
- [ ] 2. 拉取两融数据（杠杆资金）
- [ ] 3. 补充当日盘面新闻与情绪
- [ ] 4. 计算广度指标并判读
- [ ] 5. 输出结构化复盘

## Steps

1. 调用 `get_market_breadth`（工具默认取当日，东八区；可传 `date` 为 `YYYYMMDD` 指定历史交易日）获取：
   - 上涨 / 下跌 / 平盘家数、合计家数
   - 涨停 / 跌停家数
   - 沪市 / 深市 / 两市成交额

2. 调用 `get_margin_data`（`days` 默认 10，最大 60）获取最近若干交易日的：
   - 融资余额、融资净买入、融券余额、两融余额、融资余额占流通市值比

3. 可选用 `domestic_search`（`flash` 快讯 / `sentiment` 股吧情绪）补充当日盘面消息面，交叉验证情绪判断。

4. 计算并判读以下广度指标：
   - **涨跌比** = 上涨家数 / 下跌家数：> 2 偏强，1~2 中性偏强，< 0.5 偏弱。
   - **涨跌停对比**：涨停显著多于跌停 → 情绪活跃；跌停增多 → 风险偏好回落。
   - **成交额**：与近 5~10 日均值比较，放量 / 缩量决定信号可信度。
   - **两融净买入**：连续为正 → 杠杆资金加仓；连续为负且余额下降 → 去杠杆。
   - **广度与指数背离**：指数涨但涨跌比 < 1（二八分化，权重拉指数）；指数跌但涨跌比 > 1（普涨修复）。

5. 输出结构化复盘：
   - **一句话结论**（偏强 / 中性 / 偏弱）
   - **广度数据表**（家数、涨跌停、成交额）
   - **杠杆资金**（近几日融资净买入趋势）
   - **关键背离**（若有）
   - **风险提示**

## Caveats

- 北向资金（陆股通）净买入自 2024 年起不再实时/每日披露，本技能不提供北向数据；资金面以**两融**为代理指标。
- 两融数据由交易所 T+1 盘后披露，存在 T-1/T-2 滞后；节假日当日涨停池可能为空。
- 广度仅覆盖沪深两市，不含北交所。
