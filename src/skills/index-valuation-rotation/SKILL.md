# 指数估值轮动 (Index Valuation Rotation)

把一组宽基与行业指数放在一起比较，用 **PE/PB 历史分位**判断谁便宜谁贵，给出可解释的轮动线索。

## Workflow Checklist

- [ ] 1. 明确比较范围（默认宽基 + 中证全指行业，或用户指定的指数）
- [ ] 2. 拉取各指数估值与分位（get_valuation_rotation）
- [ ] 3. 结合市场参与度/拥挤度判断轮动是否已经发生（get_market_crowding）
- [ ] 4. 对候选方向查看龙头与成分（get_industry_boards / get_concept_boards）
- [ ] 5. 输出分位排序表与轮动结论

## Steps

1. **确定比较范围**
   - 默认用 `get_valuation_rotation` 的内置指数池：宽基（沪深300、中证500、中证1000、上证50、科创50、创业板指）+ 中证全指行业（能源、材料、工业、可选消费、主要消费、医药卫生、金融地产、信息技术、通信服务、公用事业）。
   - 若用户聚焦特定行业，用 `symbols` 传入对应指数代码。

2. **拉取估值分位**
   - 调用 `get_valuation_rotation`，结果按 **PE 分位升序**排列（越靠前越便宜）。
   - 关注：PE 绝对值、PE 分位、PB 分位、股息率、估值状态（低估/中估/高估）。
   - PE 分位低但 PB 分位不低时，注意盈利周期位置（周期股低谷利润会抬高 PE）。

3. **交叉验证情绪**
   - 用 `get_market_crowding` 看整体参与度与拥挤度：若拥挤度已高，即使某行业分位低也可能已被资金关注。

4. **落到标的**
   - 对看好的方向用 `get_industry_boards` / `get_concept_boards` 查看板块涨跌与领涨股。
   - 若决定配置，转 `etf-selection` 或 `asset-allocation`。

5. **输出结构**
   - 分位排序表（代码 | 名称 | PE | PB | PE分位 | PB分位 | 股息率 | 估值状态）
   - 最低估 / 最高估方向
   - 轮动逻辑与风险

## 解读要点

- **分位是相对自身历史**，不是跨指数的绝对贵贱；高成长行业天然分位偏高。
- **低分位不等于会涨**：需结合盈利趋势、政策、资金面。
- **估值轮动通常是渐进的**：低分位板块可能需要催化剂才会启动。
- **宽基 vs 行业**：宽基适合核心配置，行业更适合卫星/择时。

## Caveats

- 估值数据来自蛋卷，**不覆盖所有指数**；未收录的指数会被跳过，结果中数量可能少于请求数。
- 分位基于历史区间，样本长度随指数不同，极端行情下可能失真。
- PE 分位对周期性行业参考性较弱，建议同时看 PB 分位与股息率。
- 本内容仅供研究参考，**非投资建议**。
