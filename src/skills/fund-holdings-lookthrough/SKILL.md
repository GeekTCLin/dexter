# 基金持仓穿透 (Fund Holdings Look-through)

## Workflow Checklist

复制以下清单到回答中，逐项推进：

- [ ] 1. 确认基金代码与基本信息（净值、规模）
- [ ] 2. 拉取前十大重仓股
- [ ] 3. 按行业 / 板块归类持仓
- [ ] 4. （ETF）确认跟踪指数与同类 ETF
- [ ] 5. 输出穿透结论

## Steps

1. 用 `get_fund_quotes` 获取基金的名称、单位净值、累计净值与净值日涨跌（ETF 还会返回场内价格），确认代码与标的。

2. 用 `get_fund_holdings` 获取**最新报告期**的前十大重仓股，每只含：
   - 代码、名称、占净值比
   - 变动类型（增持 / 减持 / 新增 / 不变）与变动幅度
   - 所属行业（INDEXNAME）

3. 将重仓股按行业归并，计算前十大合计占净值比：
   - 合计占比高（> 50%）→ 集中度高，个股风险大。
   - 行业集中 → 风格暴露明显（如单一赛道）。
   - 结合变动方向判断基金经理近期是加仓还是减仓。

4. 若标的是 ETF/指数基金，用 `get_index_etf_map` 找到跟踪同一指数的其他 ETF（对比规模、公司、跟踪误差），并用 `get_index_valuation` 辅助判断指数估值位置。

5. 可选：对占比较高的重仓股，用 `get_market_data` 或 `get_index_snapshot` 看其近期表现，判断对基金净值的贡献。

6. 输出穿透结论：
   - **基金画像**（主动/被动、风格、行业偏好）
   - **重仓股表**（代码 / 名称 / 占净值比 / 变动 / 行业）
   - **集中度与风险**（前十大合计占比、单一行业占比）
   - **同类对比**（ETF 场景下）

## Caveats

- 持仓为**定期报告披露**数据（季报/半年报/年报），存在滞后，不反映最新调仓。
- 仅披露前十大重仓股，债券持仓与 FOF 持仓只给数量，不给明细。
- 占净值比来自数据源字段（`JZBL`），单位与口径以数据源为准。

## Disclaimer

以上为公开持仓数据的整理与分析，**非投资建议**。
