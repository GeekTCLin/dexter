# 资产配置 (Asset Allocation)

用**规则化模型**给出股债目标仓位与核心-卫星拆分，用指数 PE 历史分位做逆向的股债倾斜，并为每个仓位挑选规模/流动性更优的示例 ETF。

## Workflow Checklist

- [ ] 1. 确认风险偏好与核心指数
- [ ] 2. 生成配置方案（股债比例 + 核心/卫星拆分 + 估值倾斜）（get_asset_allocation）
- [ ] 3. 核对核心指数估值分位（get_index_valuation）
- [ ] 4. 复核示例 ETF（get_etf_evaluation）
- [ ] 5. 输出方案与再平衡提示

## Steps

1. **确认输入**
   - 解析用户的风险偏好：稳健（conservative）/ 平衡（balanced）/ 进取（aggressive）。
   - 确认核心宽基指数，默认 `沪深300`；若用户提到行业/主题，作为 `satellite_index`（卫星）。
   - 若用户已明确权益目标仓位，直接传 `equity_weight`。

2. **生成配置方案（核心步骤）**
   - 调用 `get_asset_allocation`，参数：`risk_level`、`core_index`、`satellite_index`、`include_etf`。
   - 规则：先按风险等级取基准权益仓位（稳健 30% / 平衡 60% / 进取 80%），再按核心指数 PE 分位倾斜——分位低（便宜）加权益、分位高（贵）减权益，单次最大调整 ±15pp。
   - 权益内部：指定卫星时按核心 70% / 卫星 30% 拆分，否则全部为核心。
   - 债券 = 100% − 权益。

3. **核对估值**
   - 用 `get_index_valuation` 确认核心指数的 PE/PB 分位与蛋卷评价，验证倾斜方向是否合理。

4. **复核示例 ETF**
   - 用 `get_etf_evaluation` 对方案推荐的 ETF 复核规模、日均成交、跟踪误差与折溢价，必要时替换。

5. **输出结构**
   - 一句话结论（目标股债比 + 是否需要再平衡）
   - 配置表（类别 | 权重 | 标的 | ETF | 规模）
   - 配置逻辑与估值依据
   - 再平衡与风险提示

## 解读要点

- **估值倾斜是逆势的**：PE 分位高时降权益，分位低时加权益，是再平衡纪律，不是择时预测。
- **核心-卫星**：核心宽基提供 beta，卫星做行业/主题 alpha；卫星比例不宜过高（默认权益的 30%）。
- **再平衡**：建议按固定周期（如每半年）或偏离阈值（如 ±5pp）再平衡，回到目标比例。
- **ETF 选择**：同一指数优先选规模大、跟踪误差小、费率低的 ETF（详见 `etf-selection`）。

## Caveats

- 本模型为**规则化配置**，未做均值方差/风险平价优化，也未纳入个人资产负债、现金流、税收与投资期限。
- 估值倾斜依赖指数 PE 历史分位（蛋卷），分位缺失时退回风险等级基准仓位。
- 债券仓位用国债/信用债 ETF 近似，未区分久期与信用风险；默认候选 `511010`、`511260`。
- ETF 推荐为"规模优先、跟踪误差次优"的示例标的，不构成推荐。
- 本内容仅供研究参考，**非投资建议**。
