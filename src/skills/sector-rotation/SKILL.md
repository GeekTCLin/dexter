# 行业轮动分析 (Sector Rotation)

## Workflow Checklist

复制以下清单到回答中，逐项推进：

- [ ] 1. 拉取行业板块强弱排名
- [ ] 2. 拉取市场广度与两融资金（背景）
- [ ] 3. 可选：下钻目标板块成分股
- [ ] 4. 可选：核对指数估值分位与相关 ETF
- [ ] 5. 补充消息面并交叉验证
- [ ] 6. 输出轮动判断

## Steps

1. 调用 `get_industry_boards`（`limit` 默认 30，最大 100）获取行业板块列表，按涨跌幅降序：
   - 板块代码（BKxxxx）、名称、涨跌幅
   - 上涨 / 下跌家数、领涨股
   - 据此划分**领涨行业**（前列）与**滞涨 / 领跌行业**（末列）。

2. 调用 `get_market_breadth` 与 `get_margin_data` 提供背景：
   - 市场广度（涨跌比、涨跌停）判断轮动是普涨、结构分化还是普跌；
   - 两融净买入判断杠杆资金是整体加仓还是减仓。

3. 若需下钻某个板块，再调用 `get_industry_boards` 并传入 `board`（板块代码如 `BK1010`，或板块名称），获取该板块成分股及当日表现。

4. 可选：对相关指数调用 `get_market_data`（子工具 `get_index_valuation`）核对估值分位，并用 `get_index_etf_map` 找到可交易的跟踪 ETF，判断行业是否“贵/便宜”以及如何表达观点。

5. 可选：用 `domestic_search`（`flash` 快讯 / `news` 关键词）补充政策、行业消息面，交叉验证轮动是否有基本面或事件驱动。

6. 输出轮动判断：
   - **一句话结论**（当前占优方向 / 防御方向）
   - **行业强弱表**（领涨 / 领跌各若干，含涨跌幅与领涨股）
   - **广度与资金印证**（是否放量、两融是否配合）
   - **估值与 ETF**（若已查询）
   - **风险提示**

## Caveats

- `get_industry_boards` 使用东方财富行业板块口径，**并非严格申万一级行业**；如需申万口径请注明差异。
- 板块数据为盘中快照（缓存 15 分钟），收盘后为当日最终值；板块内个股数量随成分调整变化。
- 行业轮动属于高频轮动信号，单日排名噪音大，建议结合 5~20 日趋势与成交量确认。
- 北向资金净买入自 2024 年起不再实时披露，资金面以**两融**为代理指标。
